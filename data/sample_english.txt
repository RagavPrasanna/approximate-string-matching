The study of algorithms is the study of method. An approximate string matching algorithm finds a pattern in a text even when a small number of edit operations has changed the text. Insertions, deletions, and substitutions each cost one unit in the Levenshtein model. Dynamic programming compares every prefix pair, while banded dynamic programming skips cells that cannot participate in a cheap alignment. Diagonal methods track only the farthest reach along each error level and use a longest common extension query to jump over exact runs. Experiments must separate time complexity from space complexity, and they must use the same machine and the same generated inputs for every competing implementation. Repetitive text and natural language place very different demands on pruning, bit parallelism, and memory. Approximate search is exact optimisation, not statistical guessing, so every reported match can be checked against a brute force reference on small inputs.
